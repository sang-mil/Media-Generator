# 모델 수동 평가표

각 항목을 1~5점으로 평가한다. 사실 정확성은 모델의 자기평가가 아니라 외부 공식 자료 또는 실제 기기 검증을 기준으로 채점한다.

## 공통 항목
- 한국어 자연스러움 (1~5)
- 지시사항 준수 (1~5)
- JSON 구조 준수 (자동 검사 결과 참조)
- 설명의 명료성 (1~5)
- 사용자가 실제로 활용할 수 있는 정도 (1~5)

## 4컷 웹툰
- 첫 컷의 공감/후킹
- 도입→문제→원인→해결 흐름
- 캐릭터 대사의 자연스러움
- 컷별 정보량과 가독성
- 저장/공유할 만한 실용성
- 기술 설명의 정확성

## 기술 설명
- 사진·동영상/앱 데이터/캐시/다운로드/시스템 데이터의 구분
- 캐시 삭제와 앱 데이터 삭제의 구분
- OS·기기별 차이 표시
- 데이터 손실 위험 경고
- 확인되지 않은 메뉴 경로·수치·기능을 지어내지 않았는지
- 모르는 부분을 명시하고 fact_check로 남겼는지

## 비교 방법
1. 같은 과제에서 Qwen과 Gemma를 비교한다.
2. 각 모델 안에서 baseline과 guarded 프롬프트를 비교한다.
3. 기술 정확성 개선이 한국어 자연스러움이나 창의성을 얼마나 희생하는지 함께 본다.
4. 첫 실행 모델 로딩 시간과 웜 실행 속도를 분리해서 본다.
5. 8개 실행만으로 최종 결론을 내리지 말고, 결과가 근접하면 주제를 바꿔 2차 테스트한다.
