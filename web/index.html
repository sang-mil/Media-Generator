자동 실행 및 안전 원칙

1. run.ps1 실행 시 Ollama 서비스가 꺼져 있으면 자동으로 시작하고 설치된 모델을 탐색합니다. 2. ComfyUI가 설치되어 있으면 기존 포터블 실행 스크립트를 찾아 시작합니다. 설치 위치가 다르면 .env의 COMFYUI_DIR를 지정하세요. 3. 스토리 설계 → 이미지 프롬프트/캡션 → 출처 대조 검수 순으로 별도 생성합니다. 4. Ollama JSON Schema와 Pydantic 검증을 적용하고 잘림/스키마 오류는 제한적으로 재시도합니다. 5. 모든 LLM 단계가 끝나면 설정에 따라 모델을 언로드해 ComfyUI용 VRAM을 확보합니다. 6. 이미지 생성이 실패해도 대본과 이미지 프롬프트는 보존합니다. 7. AI의 출처 대조는 독립적인 사실 검증이 아닙니다. 출처 원문·최신성 확인과 최종 게시 승인은 사람이 진행합니다. 8. Instagram 자동 게시와 Insights 수집은 Meta 공식 API 권한 및 계정 연결이 끝난 후 별도 활성화합니다. 9. 로컬 PC의 절전·종료 상태에서는 자동 작업이 실행되지 않습니다.
